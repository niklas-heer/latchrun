View chart data and measurement details

All durations are in milliseconds. Percentiles use completed command samples; gaps mean no samples. Cache hit rate is hits ÷ (hits + misses). Durations include provider lookup. Cache decisions count commands with credentials and caching enabled; a miss requests fresh resolution and does not guarantee success. Outcomes are grouped by command start time. Periods follow UTC boundaries; the current period is partial. Displayed times use this browser’s local timezone.

Historical analytics are retained locally across service restarts and session-history pruning. The selected window limits this view; it does not delete older records.
